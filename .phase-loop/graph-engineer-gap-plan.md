# Graph-engineer v1.1 architecture handoff

## Decision

The Graph-engineer package is locally verified as a production-useful
design-time graph validator with a strict optional pre-run gate, auditable
evidence records, and metadata-only activation/platform checks. It is not
verified as a globally authenticated host runtime, graph executor, process
supervisor, or production-ready auto-revocable platform.

The supplied Pir Panjal repair handoff is materially improved but is not fully
verified. The focused Avalanche suite is currently 161/162: the one failing
positive POC fixture still carries the old Nepal/24-hour binding after the
consumer contract was strengthened. Two input-boundary follow-ups also remain:
unsafe provider `call_id` handling and malformed POC binding types.

## GLM architecture backlog

These are the remaining high-value boundary changes. Minor wording, fixture
polish, and routine cleanup can remain with GLM after these gates.

### GLA — reconcile the strengthened release-consumer contract

1. Update the intended-valid POC fixture/helper to use the canonical decision
   ID, `ensemble_members: 1`, Pir Panjal/middle manifest fields, and 48-hour
   forecast semantics.
2. Preserve the existing shared consumer contract; do not loosen it to make
   the fixture green.
3. Add a consumer-side adversarial test that mutates the forecast manifest and
   all internal result hashes consistently; the gate must still fail.

Acceptance: a producer/consumer bundle cannot pass with a 72-hour or
multi-member forecast on the 48-hour single-member POC path.

### GLB — close the Modal URL identity gap

1. Validate provider `call_id` with the same safe-identity contract before any
   URL construction.
2. Reject slash, dot-segment, query, fragment, control, and overlong values.
3. Prefer URL-segment encoding plus an allowlist; never rely on string
   concatenation for provider identifiers.
4. Add a regression test for `../escape`, `%2F`, query/fragment text, and a
   257-character ID, asserting no poll request is made.

Acceptance: no provider response can alter the poll target path while retaining
the authenticated worker origin.

### GLC — make malformed POC bindings fail cleanly

1. Treat non-integer/string/boolean horizon and ensemble binding fields as
   structured `PocScopeError` violations, not uncaught `ValueError` exceptions.
2. Add malformed JSON binding tests and assert a nonzero gate result without a
   traceback.

Acceptance: malformed POC scope metadata fails closed with an actionable error.

### GLD — prove the actual host/workflow layer

1. Run the focused suites in the repository’s supported CI import context.
2. Execute a workflow syntax/lint check accepted by GitHub Actions.
3. Perform authenticated, non-publishing smoke tests for every Modal route and
   the POC release path with redacted evidence.
4. Keep the human gate closed until pinned native artifacts, DGRE approval, and
   independent labels exist.

Acceptance: report source/test proof separately from authenticated host and
remote execution proof.
