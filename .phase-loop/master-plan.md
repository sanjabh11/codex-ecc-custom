# Cross-Repository Marketing Skill Adoption

## Objective

Audit the pinned `ericosiu/ai-marketing-skills` snapshot against the five active repositories, implement the ten highest-value capabilities as ECC-native skills, validate them with deterministic evidence, and project only passing canonical content to the four active runtime roots.

## Phase Gates

1. **P1 — Reconnaissance:** five repository fingerprints, upstream provenance, and 22-skill inventory.
2. **P2 — Selection:** weighted 22×5 scoring, top-ten matrix, threat model, and dispositions.
3. **P3 — Canonical implementation:** ten skill packages, five profiles each, adoption manifests, and repo prompts.
4. **P4 — Verification:** quick validation, portfolio validator, unit tests, evidence-schema validation, and forbidden-pattern scan.
5. **P5 — Projection:** four-runtime copies, content parity, and final handoff with residual risks.

## Stop Conditions

- Stop before live outreach, CRM/campaign mutation, payment, deployment, credential use, or destructive changes.
- Stop if any skill loses required frontmatter, scenario coverage, claim boundary, or unavailable-state behavior.
- Preserve unrelated user edits and do not modify the four audited product repositories.
