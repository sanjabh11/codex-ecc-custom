## Adaptation Notes

### Value Equation (Source 1)
The original Value Equation is `Value = (Dream Outcome x Perceived Likelihood) / (Time Delay x Effort & Sacrifice)`. This skill adapts it by:
1. Converting each dimension to a 1-10 integer score
2. Inverting Time Delay and Effort so 10 = best (fastest/least effort)
3. Computing a deterministic composite: `(Dream x Likelihood) / ((11 - Time) x (11 - Effort)) x 10`
4. Requiring evidence citations for all claims within offers

### Hook Formulas (Sources 4, 6)
Hormozi identifies pain, desire, proof, and curiosity as the four hook triggers. This skill adapts by:
1. Extracting hook examples from the positioning audit's evidence corpus
2. Tagging each hook with an awareness level (unaware, problem-aware, solution-aware, product-aware)
3. Requiring evidence citations for all hook claims
4. Adding a deterministic ranking system (clarity, curiosity, pull)

### Content Batching (Source 7)
Hormozi's content clipping strategy involves recording long-form content and clipping into 250+ short-form pieces. This skill adapts by:
1. Using positioning audit findings as the "long-form" source material
2. Producing 20 short-form ideas per long-form piece (not 250+)
3. Enforcing proof-loop injection (50%+ content cites evidence)
4. Formatting per platform with specific constraints

### SPCL Framework (Source 8)
Hormozi's SPCL (Status, Power, Credibility, Likeness) measures influence. This skill does not directly implement SPCL scoring but uses its principles to guide proof asset categorization and authority building.
