# SEO Opportunity Loop

## Objective

Extend technical SEO into a measured opportunity and content-maintenance loop.

## Operating Contract

1. Run technical/indexability checks before content expansion and identify the intended public surface.
2. Map audience jobs and product proof to existing routes; reject topics that require unsupported claims.
3. Use verified GSC or equivalent analytics when available. If credentials are absent, return `unavailable` for performance claims and use source-backed planning only.
4. Score opportunities by intent fit, evidence strength, attainable differentiation, route readiness, and maintenance cost.
5. Create or update a brief with source dates, internal-link plan, schema needs, and conversion measurement.
6. Read results after the declared window and promote, revise, or retire the playbook rule.

## Required Outputs

- technical blocker list
- keyword/topic-to-route map
- prioritized briefs
- readback decision

## Proof and Safety

- Use the proof buckets `hosted/live`, `local`, `repository artifact`, `candidate/shadow`, and `roadmap`.
- Cite the source of load-bearing claims and label inference, uncertainty, contradiction, and stale evidence.
- Return `unavailable` when required data, tools, consent, or credentials are missing.
- Default external communications and system mutations to draft or dry-run. Require explicit approval in the current turn before any send, enrollment, publish, payment, CRM write, or production action.
- Preserve product-specific safety, scientific, regulatory, privacy, and buyer-evidence gates.
- Do not add dependencies for a text-and-evidence workflow.

## Routing

Use adjacent skills rather than reproducing them: `seo`, `content-engine`, `ecc-closed-loop-analytics`. This skill owns only the closed capability described above.
